# 闲鱼状态与弹窗处理手册

日期：2026-06-22  
用途：把页面打开后的状态判断标准化，后续看到 loading、空态、登录、无权限、二维码、确认弹窗、上传下载或高风险业务态时，按同一套规则处理。  
边界：本手册只记录状态类别、可读结构和停止规则；不记录真实账号、订单、地址、聊天、商品标题、金额、经营数字、图片链接、二维码内容或登录材料。

总索引：`goofish-master-index.md`  
机器规则：`goofish-state-modal-rules.json`  
状态清单：`goofish-page-state-modal-inventory.md`  
探测规程：`goofish-safe-probe-protocol.md`  
动作规则：`goofish-action-gate-rules.json`

## S0-S10 状态

| 状态 | 名称 | 可以读 | 下一步 |
| --- | --- | --- | --- |
| S0 | 正常内容 | 标题、tab、表头、字段名、按钮名、状态类别 | 继续只读 |
| S1 | 加载中 | loading 类型、路由形态 | 等锚点或空态，不急着点 |
| S2 | 空态 | 空态类别、容器、tab、字段名 | 记录空态，不造数据 |
| S3 | 网络或接口失败 | 错误类别、重试按钮名、路由 | 可安全刷新一次，失败就停 |
| S4 | 登录态失效 | 登录门禁类型 | 等用户登录，不保存登录材料 |
| S5 | 权限或身份门禁 | 无权限、账号检查、站点选择类型 | 只记录门禁，不切号不继续 |
| S6 | 二维码或 APP 承接 | 承接类型、按钮类别 | 不扫码、不保存二维码、不外跳 |
| S7 | 确认弹窗 | 弹窗类别、取消/确认按钮类别 | 不点确认，先判断后果 |
| S8 | 表单校验 | 字段名、校验类别、输入类型 | 可改草稿，提交前停 |
| S9 | 文件或导出 | 上传/下载/导出类别 | 文件传输前确认范围和目标 |
| S10 | 高风险业务态 | 状态类别、字段名、按钮类别 | 只读标签，不改业务状态 |

## 状态优先级

1. S10 高风险业务态优先级最高。
2. S7 确认弹窗出现时，不因为原页面低风险而默认确认。
3. S4 登录和 S5 门禁必须停，除非用户本人处理完成。
4. S9 文件/导出出现时，先确认范围和目标。
5. S8 表单校验只允许草稿修正，不等于允许提交。
6. S2 空态是有效结果，不通过新增、发布、联系、下单来制造数据。

## 页面族常见状态

| 页面族 | 常见状态 | 处理 |
| --- | --- | --- |
| 公开发现 | S0/S1/S2/S3/S6 | 可读公开结构，APP 承接停 |
| 商品详情 | S0/S1/S2/S6/S7/S10 | 商品结构可读，购买/联系/收藏停 |
| 买家账号 | S0/S1/S2/S4/S6/S7 | 只读账号结构，编辑资料/切号停 |
| 买家交易 | S0/S1/S2/S4/S6/S7/S10 | 只读订单状态，支付/退款/评价停 |
| 草稿输入 | S0/S1/S4/S7/S8/S9 | 可改草稿，上传/保存/发布停 |
| 消息 | S0/S1/S2/S4/S7/S9 | 只看外壳，不打开私聊或发送 |
| 身份门禁 | S4/S5/S6 | 用户本人处理，不代过验证 |
| 卖家数据 | S0/S1/S2/S3/S6/S9 | 只读字段和图表类别，不导出 |
| 卖家商品 | S0/S1/S2/S7/S8/S9/S10 | 只读表头和草稿，经营动作停 |
| 卖家交易 | S0/S1/S2/S7/S10 | 只读表头和状态，发货/售后/投诉停 |
| 卖家财务 | S0/S1/S2/S7/S9/S10 | 只读表头，不导出不记录金额 |
| 卖家账号/安全/推广 | S0/S1/S2/S5/S7/S10 | 只读权限/风险/计划结构，变更停 |
| 卖家消息 | S0/S1/S2/S7/S9 | 只看消息外壳，不读具体私聊 |
| 卖家门禁/外壳 | S0/S1/S3/S4/S5/S6/S9 | 只识别容器和门禁，不跨出去操作 |

## 脚本判断顺序

```text
1. 读 route/hash 和 pageId
2. 查 manifest.family
3. 等待 S0/S2/S3/S4/S5/S6/S7/S8/S9/S10 任一稳定信号
4. 若出现 S10/S7/S4/S5/S9，先停
5. 若是 S1，继续等或安全失败
6. 若是 S2，记录空态
7. 若是 S0，继续字段/控件只读
```

## 弹窗处理

| 弹窗 | 处理 |
| --- | --- |
| 登录/扫码/验证码 | 用户本人处理，不保存材料 |
| 删除/关闭/下架/退款/支付/发货/投诉/认证 | 不点确认 |
| 上传/下载/导出 | 先确认数据范围、目标和后果 |
| 错误/失败/重试 | 可安全刷新一次 |
| 纯说明 | 只读标题和字段名，关闭前确认不是提交 |

## 输出模板

```text
页面：<pageId / routeShape>
页面族：<family>
状态：<S0-S10>
锚点：<标题 / tab / 表头 / 卡片 / 输入区 / 空态>
可读：字段名、按钮名、状态类别、控件类别
下一步：继续只读 / 等待 / 记录空态 / 需用户登录 / 需用户确认 / 停止
隐私：不记录真实账号、订单、地址、聊天、商品标题、金额、图片、二维码或登录材料
```

结论：页面“打开了”不是终点，必须先过 S0-S10 状态判断。只有 S0 和部分 S2/S3 能继续只读；S4/S5/S6/S7/S9/S10 默认停，S8 只允许草稿层辅助。
