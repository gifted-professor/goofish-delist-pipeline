## 控件风险层

| 层级 | 控件类型 | 例子 | 默认处理 |
| --- | --- | --- | --- |
| C0 | 导航和展示控件 | Logo、页签、标题、只读卡片、返回、关闭 | 可读，可截图 |
| C1 | 只读筛选控件 | 搜索、排序、价格区间、日期范围、状态 tab | 可改筛选，但不触发业务状态 |
| C2 | 草稿输入控件 | 发布描述、反馈文本、IM 输入框、售后/申诉草稿 | 可填草稿，提交前停 |
| C3 | 外部或文件控件 | 上传、下载、导出、二维码、打开客户端 | 确认目标和范围后才操作 |
| C4 | 业务提交控件 | 发布、提交订单、支付、发货、同意退款、保存权限 | 禁止主动触发 |

控件判断顺序：

1. 先判断控件所在页面是否公开、登录、交易、经营、权限或登录流程。
2. 再判断控件是读状态、改筛选、写草稿、传文件，还是提交业务。
3. 弹窗里的同名按钮风险更高；弹窗里的“确定”不能当作安全默认操作。
4. 表格里的“操作”列通常是高风险入口，只读时只记录列名。

| 反馈入口 | 主站侧边工具条、反馈页 | 反馈类型、问题页面、文本框 | 草稿可写；截图/提交前确认 |

## 通用列表和表格控件

| 控件 | 典型页面 | 可做 | 停止点 |
| --- | --- | --- | --- |
| 状态 tab | 收藏、订单、商品管理、退款、评价、投诉、财务 | 切换 tab、读状态类别 | tab 下的操作按钮另判 |
| 搜索框 | 搜索页、卖家列表页、IM、通知 | 输入关键词或读搜索结构 | 搜索具体隐私对象前确认 |
| 筛选面板 | 搜索、商品管理、订单、退款、评价、财务 | 读筛选项、改非敏感筛选 | 涉及账号/订单/客户条件时脱敏 |
| 日期范围 | 数据、订单、财务、客服、推广 | 选择开始/结束日期 | 导出/下载前确认 |
| 表头 | 卖家表格、订单列表、财务列表 | 读取列名 | 不读取真实行值 |
| 分页 | 列表页、数据表格 | 上一页、下一页、跳至、条/页 | 翻页会加载更多隐私行，摘要仍脱敏 |
| 更多菜单 | 订单、商品、列表卡片 | 只识别菜单存在 | 菜单内编辑/删除/发货/退款前确认 |
| 操作列 | 卖家表格 | 只记录列名 | 操作列按钮默认 C3/C4 |

## 表单和弹窗控件

| 控件 | 典型页面 | 可辅助 | 停止点 |
| --- | --- | --- | --- |
| 文本框 | 发布、反馈、IM、售后、投诉 | 写草稿、改措辞 | 提交/发送前确认 |
| 数字输入 | 价格、数量、库存、运费、投放预算 | 检查格式和上下限 | 保存/发布/投放前确认 |
| 规格选择 | 商品详情、确认订单、发布 | 识别规格层和库存状态 | 购买/下单前确认 |
| 地址选择 | 确认订单、发货、退货地址、运费模板 | 只读字段名或草稿结构 | 管理、添加、修改、保存前确认 |
| 图片/文件上传 | 发布、反馈、售后、IM、发货导入 | 检查格式和数量限制 | 上传前确认文件和目标 |
| 二维码弹层 | 登录、APP 查看、地址管理、付款、认证 | 识别用途 | 用户本人扫码；不保存二维码 |

| 成功/失败提示 | 反馈、收藏、上传、网络错误 | 记录状态类别 | 不重复提交 |

## 稳定定位建议

| 场景 | 优先锚点 | 避免 |
| --- | --- | --- |
| 主站搜索 | 搜索框、排序选中态、价格输入框、商品卡容器 | 整页文本、页脚 SEO 链接 |
| 商品详情 | 商品主区、价格区、卖家卡、推荐区 | 直接点购买/联系 |
| 登录页 | 登录页标题、扫码容器、验证码入口类型 | 读取二维码内容 |
| 表格页 | 页面标题、状态 tab、表头、分页 | 读取真实行值 |
| 发布/反馈 | 字段 label、上传区、提交按钮 | 直接提交 |
| 订单/售后 | 状态节点、字段名、按钮名 | 真实订单号、地址、金额 |
| 工作台外壳 | hash、左侧菜单、页面标题 | 把 iframe 或下载页当业务页 |
| 弹窗 | 标题、正文中的动作词、按钮组 | 默认点击“确定” |

## 自动化读取顺序

1. 先用 URL/hash 定位页面。
2. 等待页面标题、tab、表头、商品卡、输入区或空态出现。
3. 读取 C0/C1 控件结构。
4. 如需要输入，只填 C2 草稿控件。
5. 遇到 C3/C4 控件时停下，说明文件/外部/业务后果。
6. 弹窗出现时先分类，不自动点确定。
7. 输出时只写控件类型、字段名、按钮名、状态类别和风险等级。

## 不稳定控件和误点风险

- 搜索页地区控件和小分页距离近，必须确认弹层已经打开。
- URL 不一定反映搜索排序、标签筛选和页内 tab 状态，要读可见选中态。
- 表格组件会出现通用筛选、排序、删除、上传、分页文案，不代表当前页面允许执行这些动作。
- `操作` 列里的按钮风险取决于页面类型；订单、售后、财务、权限页默认高风险。
- 二维码弹层可能用于 APP 查看、付款、认证、地址管理或登录，只记录用途，不保存内容。
- 下载入口可能是报表、明细、客户端或文件，确认前不要点击。
