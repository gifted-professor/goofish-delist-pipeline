## 主站入口判断

| 入口状态 | 典型信号 | 含义 | 处理 |
| --- | --- | --- | --- |
| 公开发现 | 首页、搜索框、频道、商品卡 | 不依赖登录的浏览层 | 可搜索、筛选、只读商品结构 |
| 登录买家 | 个人主页、收藏、买到的、账号、消息 | 当前 Profile 已登录 | 只读字段名和状态类别，输出脱敏 |
| 交易链路 | 确认订单、订单详情、支付结果 | 涉及订单、支付、物流、售后 | 只读核对，状态变更前停 |
| 草稿输入 | 发布、反馈、IM 草稿 | 可以帮写文字或表单草稿 | 上传、保存、提交、发送前停 |
| 身份门禁 | 登录、找回账号、选择账号、登录校验 | 需要用户本人处理 | 不代填验证码，不切号 |
| 内部/边缘 | API 模块、视频布局、浏览器升级、实验页 | 非常规业务页或边界页 | 只识别，不主动触发 |

## 主站巡检顺序

1. 先看域名和 path，确认是 `www.goofish.com` 主站而不是工作台或 H5/App 承接页。
2. 公开页面先读搜索框、频道、商品卡、详情主区和卖家公开卡。
3. 登录页面先判断是否是个人、收藏、订单、账号、消息或发布。
4. 交易页面先降级为只读核对，不提交、不付款、不确认收货、不退款。
5. 输入页只写草稿；任何上传、保存、提交、发送都停。
6. 身份页只辅助打开；扫码、验证码、找回、切号、认证都交给用户本人。

## 可记录和不可记录

| 类型 | 可以记录 | 不记录 |
| --- | --- | --- |
| 公开发现 | 搜索条件、筛选控件、卡片字段结构、页面族 | 具体商品标题、商品 ID、卖家昵称 |
| 商品详情 | 字段名、保障标签类别、按钮名、推荐区结构 | 具体标题、图片链接、卖家身份、商品 ID |
| 个人/收藏 | tab、表头、状态类别、入口关系 | 账号名、头像 URL、收藏商品真实内容 |
| 订单/交易 | 字段名、状态节点名、物流模块名、按钮名 | 订单号、地址、物流号、金额、商品标题 |
| 发布/反馈 | 表单字段名、校验类型、草稿意图 | 真实图片、具体位置、截图内容 |
| 消息 | 会话框架、输入区、工具栏、按钮名 | 联系人、聊天正文、商品/订单卡内容 |
| 账号/身份 | 模块名、状态类别、门禁类型 | 二维码、验证码、手机号、密码、证件、账号名 |

## 自动化准入

| 动作 | 默认等级 | 规则 |
| --- | --- | --- |
| 打开公开页、搜索、滚动 | G0 | 可执行，输出不写真实商品身份 |
| 切换公开筛选、价格区间、排序 | G0/G1 | 可以执行；地区弹层不稳定时停止 |
| 打开详情、他人主页 | G0/G1 | 只读结构，不关注/联系/购买 |
| 打开登录后列表 | G1 | 只读字段名和状态类别，摘要脱敏 |
| 填写发布/反馈/消息草稿 | G2 | 不上传、不保存、不提交、不发送 |
| 收藏、关注、我想要、联系 | G3 | 改变账号状态或沟通意向，必须确认 |
| 下单、支付、确认收货、退款、评价 | G4 | 不主动触发 |
| 登录、找回、切号、认证、验证码 | G4 | 用户本人处理 |
| 访问内部实验/API 模块 | G4 | 禁止主动访问或调用 |

## 多账号主站规则

- 一个闲鱼账号对应一个独立浏览器 Profile。
- 自动化只保存账号别名和 Profile 路径，不保存密码、验证码、cookie、token 或本地存储。
- 每次打开 `/account`、`/personal`、`/bought`、`/collection`、`/im` 前都重新确认当前 Profile 登录态。
- 如果出现 `/login`、`/select-account`、`/find-account`、`/login-validation`，立即停下让用户本人处理。
- 不在一个 Profile 内反复切账号；需要换账号就切换到另一个 Profile。

结论：主站页面可以分成公开发现、登录买家、交易链路、草稿输入、身份门禁和内部边界六层。公开找货可以自动化只读；登录、订单、发布、消息和账号相关页面只能脱敏只读或草稿辅助；所有交易、发送、上传、保存、认证和切号动作都必须停下确认。
