# 闲鱼自发布商品指标读取说明

日期：2026-06-22  
用途：把“自己发布商品里的想要、浏览数能不能看”沉成一个可执行的小闭环。适合后续做只读统计前先确认入口、字段、停止点和授权边界。  
边界：默认只记录字段是否可见、页面位置和风险类别；不记录真实账号、店铺、商品标题、商品 id、价格、图片链接、买家/卖家身份、聊天、订单、具体指标数字或登录材料。若要记录具体数字，需要用户单独明确授权。

## 当前实测结论

| 位置 | 想要字段 | 浏览字段 | 结论 |
| --- | --- | --- | --- |
| `/personal` 进入的“我发布的”列表卡片 | 未稳定暴露 | 未稳定暴露 | 列表可作为商品详情入口来源，不适合作为指标读取来源 |
| `/item?id=<id>&categoryId=<categoryId>` 商品详情页 | 可见相关信号 | 可见相关信号 | 详情页适合作为只读指标来源，但同页存在高风险管理/交易动作 |

## 推荐读取路径

1. 打开当前账号 Profile 的 `/personal`。
2. 切到“我发布的”或等价发布列表区域。
3. 只提取商品详情链接的路由形状，不保存真实商品标题、图片、价格或 id。
4. 打开商品详情页。
5. 在详情页只读识别“想要/我想要/人想要”和“浏览/浏览数/人浏览/曝光”字段是否出现。
6. 默认只落账字段可见性；如用户授权，再记录数字类别或具体数字。
7. 遇到购买、聊一聊、编辑、下架、删除、擦亮、发布、确认、登录、验证码、扫码时立即停止。

## 字段落账规则

| 字段 | 默认是否可记录 | 授权后是否可记录具体值 | 风险说明 |
| --- | --- | --- | --- |
| 指标是否可见 | 可以 | 可以 | 只写 true/false，不涉及业务值 |
| 指标字段名 | 可以 | 可以 | 例如“想要”“浏览数”这类字段名 |
| 指标数字 | 不默认记录 | 用户明确授权后可以 | 属于商品经营表现数据 |
| 商品详情路由形状 | 可以 | 可以 | 只写参数名，不写真实参数值 |
| 商品真实 id | 不记录 | 通常不建议记录 | 可关联真实商品 |
| 商品标题/图片/价格 | 不记录 | 需单独授权 | 属于商品身份和业务内容 |
| 账号/Profile | 只写别名 | 只写别名 | 不写真实会员名、手机号或店铺名 |

## 安全停止点

| 类别 | 停止词/控件 | 处理 |
| --- | --- | --- |
| 买家动作 | 我想要、立即购买、聊一聊 | 只识别为动作边界，不点击 |
| 卖家管理 | 编辑、下架、删除、擦亮、管理 | 只识别为管理边界，不点击 |
| 发布/提交 | 发布、保存、确认、提交 | 停止，不进入提交链路 |
| 登录门禁 | 登录、扫码、验证码、安全验证 | 停止，由用户本人处理 |
| 外部承接 | App、下载、打开客户端 | 停止，不跳外部 |

## 自动化判断

- 如果目标只是确认“能不能看”，记录 `detailWantMetricVisible` 和 `detailViewMetricVisible` 即可。
- 如果目标是做统计表，先让用户明确授权记录具体数字，并仍然不记录商品标题、图片、价格、真实 id 或账号名。
- 如果列表页没有稳定出现指标，不要在列表页硬抓；进入详情页读取。
- 如果详情页出现动作按钮，这是正常现象，不代表可以点击；它只说明页面需要高风险动作门禁。

结论：自发布商品的“想要”和“浏览数”应以详情页为主要读取点，列表页只作为详情入口。后续若要做多账号商品指标统计，应按 Profile 隔离账号，并在用户授权后才记录具体指标数字。
