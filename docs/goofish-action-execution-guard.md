# 闲鱼动作执行防护

日期：2026-06-22  
用途：把页面上的按钮、链接、输入框、弹窗和接口词统一套进 G0-G4 动作门禁，方便后续只读熟悉页面或写脚本时先判定能不能动。  
边界：本防护只记录动作类别、按钮类别、接口词和停止规则；不记录真实账号、订单、地址、聊天、商品标题、金额、经营数字、图片链接或登录材料。

总索引：`goofish-master-index.md`  
机器规则：`goofish-action-gate-rules.json`  
动作矩阵：`goofish-action-gate-matrix.md`  
接口对照：`goofish-page-api-crosswalk.md`  
流转图：`goofish-page-transition-graph.json`

## 先判定，再动作

看到按钮或链接时，按这个顺序判断：

1. 先看当前页面 id 和页面族。
2. 再看流转图里当前页到目标页属于 `SAFE_READ`、`READ_WITH_REDACTION`、`REQUIRES_USER_CONTEXT`、`STOP_BEFORE_ACTION`、`STATIC_ONLY` 还是 `SHELL_ONLY`。
3. 再看按钮文案、控件类型、弹窗状态和接口词。
4. 最后取最高风险等级，得到 G0-G4。

## G0/G1 可以只读

| 等级 | 可以做 | 典型动作 |
| --- | --- | --- |
| G0 | 公开只读 | 搜索、筛选、排序、展开、收起、返回、关闭、滚动 |
| G1 | 登录只读 | 查看字段名、tab、表头、状态类别、按钮名、空态 |

G1 只代表可以看结构，不代表可以记录真实值。订单、财务、地址、聊天、经营指标都只写字段名和状态类别。

## G2 只能草稿

| 场景 | 可以做 | 必须停 |
| --- | --- | --- |
| 发布页 | 读字段名、准备标题/描述/价格草稿 | 上传、保存、发布 |
| 反馈页 | 写反馈草稿 | 上传截图、提交 |
| 消息页 | 拟消息文本 | 打开具体私聊、发送、发文件 |
| 运费模板/客服规则 | 准备规则草稿 | 保存、启停、设默认 |

## G3 要用户确认

这些动作可能改变账号或经营状态，不能默认点：

- 收藏、取消收藏、关注、取消关注、我想要。
- 联系、发送、发商品卡、发订单卡。
- 保存、提交、确定、确认、创建、新建、申请。
- 导出、下载、打开外部链接、安装。
- 编辑、更新、备注、标已读、清未读、拉黑。
- 切换站点、切换账号、保存客服分流规则。

G3 的确认必须在动作发生前问，不能用“之前你让我继续”来替代。

## G4 不主动触发

这些动作默认只说明风险，不执行：

- 立即购买、提交订单、支付。
- 确认收货、延长收货、取消订单、关闭订单。
- 退款、同意退款、拒绝退款、赔付。
- 发货、改物流、批量发货、上传 Excel。
- 投诉、纠纷、举证、申诉、举报。
- 实名认证、验证码、扫码、安全认证。
- 改权限、新建子账号、停用账号。
- 新建付费推广计划、投放。
- 内部测试、支付测试、账号测试。

## 控件风险

| 控件 | 默认处理 |
| --- | --- |
| 链接 | 先查流转图；深层参数页必须等用户上下文 |
| 普通按钮 | 看文案、弹窗和页面族；不认识时按更高风险 |
| 文本输入 | 搜索/筛选是 G0/G1，草稿是 G2 |
| 文本域 | 草稿 G2；提交前停 |
| 文件选择 | G3/G4；不默认上传 |
| 复选框/单选框 | 筛选可读；订单、财务、权限、发票、发布设置里升级 |
| 下拉框 | 筛选可读；地址、物流、支付、权限、分流里升级 |
| 下载/导出 | G3；不默认下载 |
| 确认弹窗 | G3/G4；不点确认 |

## 接口词风险

| 接口词 | 默认等级 |
| --- | --- |
| `search`, `suggest`, `feed`, `filter` | G0/G1 |
| `query`, `list`, `render`, `detail`, `summary` | G1 |
| `preget`, `precheck`, `draft` | G2 |
| `create`, `publish`, `submit`, `apply`, `save`, `edit`, `update`, `remark`, `export`, `download`, `send` | G3 |
| `pay`, `refund`, `compensate`, `refuse`, `agree`, `consign`, `logistics`, `proof`, `dispute`, `complain`, `appeal`, `identity`, `verify`, `permission`, `test` | G4 |

## 确认请求格式

需要确认时，只写这些：

```text
账号 Profile：<别名>
页面：<pageId / routeShape>
动作：<按钮或动作类别>
等级：G3/G4
预计影响：<账号 / 商品 / 交易 / 消息 / 财务 / 权限 / 本机下载>
将记录：字段名、按钮类别、状态类别
不会记录：真实账号、订单、地址、聊天、商品标题、金额、图片或登录材料
```

结论：后续熟悉页面时，只读动作走 G0/G1，草稿走 G2，G3 先确认，G4 默认不主动触发。任何脚本都应该先读 `goofish-action-gate-rules.json`，再决定是否能操作页面控件。
