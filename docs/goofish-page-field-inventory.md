# 闲鱼页面字段清单

日期：2026-06-22  
来源：页面地图、路由索引、动作门禁矩阵、静态接口审计，以及已登录只读探索。  
用途：按页面记录“能读哪些字段、哪些字段只能脱敏、哪些字段不能写入日志或文档”。本清单只写字段类型，不写真实账号、订单、地址、聊天、商品标题、金额或经营数据。

总索引：`goofish-master-index.md`，用于从当前所有页面理解文档中选择查阅路径。

配套机器可读清单：`goofish-page-manifest.json`，用于按页面 id 对齐字段敏感等级和可记录范围。

配套站点层级：`goofish-site-taxonomy.md`，用于判断字段属于主站公开页、登录买家页、交易页、卖家经营页还是门禁/容器页。

配套逐页就绪矩阵：`goofish-page-readiness-matrix.md`，用于把页面字段、证据、风险和停止点合并检查。

配套任务流手册：`goofish-task-workflow-runbook.md`，用于判断字段出现在搜索、订单、发布、售后、财务、权限等哪类任务路径中。

配套控件清单：`goofish-ui-control-inventory.md`，用于判断字段所在控件是只读展示、筛选输入、草稿输入、上传下载还是业务提交。

配套页面接口对照：`goofish-page-api-crosswalk.md`，用于判断字段所在页面背后的读取、写入和高风险接口能力。

配套状态清单：`goofish-page-state-modal-inventory.md`，用于判断字段出现时对应的是正常内容、空态、弹窗、门禁还是高风险业务态。

## 字段敏感等级

| 等级 | 名称 | 说明 | 记录规则 |
| --- | --- | --- | --- |
| F0 | 公共结构 | 页面标题、tab、按钮名、字段名、表头名 | 可记录 |
| F1 | 公开商品 | 公开商品卡上的价格区间、地区类别、保障标签、想要人数类别 | 可脱敏摘要，不写具体商品标题或 ID |
| F2 | 账号内列表 | 收藏、订单、消息、个人主页、卖家后台列表 | 只写状态类别和字段名 |
| F3 | 交易/经营 | 订单、物流、退款、财务、发票、客服、粉丝、推广 | 只写字段名，不写真实值 |
| F4 | 身份/安全 | 会员名、手机号、证件、支付宝、认证、二维码、cookie/token | 禁止记录 |

## 字段读取优先级

1. 优先读页面标题、tab、按钮名、字段名、表头名。
2. 再读状态类别，例如待付款、待发货、售后中、已关闭这类状态标签。
3. 对公开商品页，只做脱敏比较，不写具体标题、ID、卖家身份。
4. 对订单、财务、发票、客服、投诉、安全中心，只写字段和状态类别，不写真实值。
5. 对账号、登录、认证、支付、二维码、cookie/token，一律不记录具体内容。

## 输出格式建议

安全摘要可以写：

- 页面：`#/seller-trade/order-manage`
- 字段：订单状态、发货/退款状态、操作
- 状态：存在待处理类状态
- 风险：发货、改物流、联系买家前确认

禁止写入文档或日志：

- 真实订单号、真实商品名、真实买家/卖家、真实地址、真实金额、真实聊天内容。
